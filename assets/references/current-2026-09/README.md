# Dated White House reference library

Collected September 27, 2026. Open `index.html` for the browsable catalog, or use `contact-01.jpg` through `contact-12.jpg` for an overview. `manifest.json` records each original image URL, page, caption and file hash. The photographs have been resized for reference viewing. Keep attribution and date metadata with them.

The 350 downloaded photographs and the NCPC public report are research material; they are not included in the browser game's published assets. Source inclusion does not imply endorsement. Current official photos and historical/planning references must not be treated as interchangeable. The implementation decisions and remaining uncertainty are documented in `docs/reference-audit-2026-09-27.md` at the repository root.
